# Accounting Agent, Loops, and Graphs Lab

An interactive, self-contained learning lab for accounting teams to explore AI agents, loops, and workflow graphs.

## Use the lab

Open `index.html` in a modern browser. It also runs offline: download the repository ZIP, extract it, and open `index.html`.

No installation, account, API key, or build step is required.

## What is inside

- Interactive conceptual diagrams for agents, loops, and graphs.
- A fictional accounting workflow with normal, missing-document, and conflicting-value scenarios.
- Step-by-step controls, human review gates, a facilitator guide, and knowledge checks.
- Camera controls and a mobile-friendly layout.

## Privacy and scope

This is an educational simulation. All examples are fictional. It contains no real client records, makes no network/API calls, and is not connected to a live AI model, accounting system, or external service. Nothing is filed, sent, or changed in a real system.

Do not treat its examples as accounting, tax, legal, or financial advice.

## GitHub Pages

Publish the `main` branch from the repository root in **Settings → Pages**. The `.nojekyll` file allows the static HTML to be served directly. GitHub Pages supports this public static site without a paid hosting plan, subject to GitHub's terms and usage limits.

## Files

- `index.html`: all application markup, styling, and JavaScript.
- `.nojekyll`: disables Jekyll processing for this static site.
