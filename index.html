02 / LOOP

How does the work continue?

Observe → decide → act → check. Repeat only when needed, with a stopping rule. Think: prepare, reconcile, revise.

03 / GRAPH

Which route can the work take?

Nodes are steps. Edges connect them. Conditions select a route, and cycles allow another pass. Think: a workflow map with branches.

Facilitator notes

An 8-minute teaching path.

  1. Agent, 2 minutes. Tap Goal, Tools, and Guardrails. Ask: “What is the assistant allowed to do, and what is it not allowed to do?”
  2. Loop, 2 minutes. Read the cycle out loud: observe, decide, act, check. Explain that an output becomes the next observation.
  3. Graph, 3 minutes. Play the complete packet, then switch to the missing-document scenario. Pause at the human gate. Ask what should happen next.
  4. Explain it back, 1 minute. Use the knowledge check. Ask the learner to sketch a workflow from their own practice.

Key distinction: A graph is not automatically an agent. Many graph steps are fixed code or human tasks. An agent may work inside one node, and a loop may span several nodes.

Learning add-ons: tools are capabilities, state is the working record, and guardrails limit what may happen. The moving diagram is a conceptual map, not a view of model internals.
